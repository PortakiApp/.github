## Issues GitHub

- **Bug** ou régression : ouvrir une issue dans le dépôt concerné avec le modèle *Bug report*.
- **Idée / amélioration** : modèle *Feature request*.
- **Question d’usage** : préférer les discussions du dépôt si activées, sinon une issue étiquetée `question`.

Inclure la version (tag npm, commit, module id), l’environnement et les logs **sans données personnelles**.
