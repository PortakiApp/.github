# PortakiApp/.github

Dépôt **public** de l’organisation [PortakiApp](https://github.com/PortakiApp). GitHub l’utilise comme source de **fichiers communauté par défaut** pour tous les dépôts de l’org qui n’ont pas leur propre copie.

## Contenu

| Chemin | Rôle |
|--------|------|
| [`profile/README.md`](profile/README.md) | Profil organisation — vue **publique** (onglet Overview) |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Guide de contribution par défaut |
| [`SECURITY.md`](SECURITY.md) | Politique de divulgation responsable |
| [`SUPPORT.md`](SUPPORT.md) | Obtenir de l’aide (issues, docs) |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Code de conduite |
| [`pull_request_template.md`](pull_request_template.md) | Modèle de PR par défaut |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Formulaires d’issues par défaut |
| [`docs/repositories.md`](docs/repositories.md) | Cartographie des dépôts **publics** |

## Dépôt complémentaire

- **[`.github-private`](https://github.com/PortakiApp/.github-private)** (privé) : README profil **membres**, modèles et docs internes (GPR, dépôts privés, onboarding équipe).

## Priorité des fichiers

Un dépôt qui définit son propre `CONTRIBUTING.md`, `SECURITY.md`, etc. **remplace** le défaut de ce dépôt. Les modèles dans `.github/ISSUE_TEMPLATE/` du dépôt cible remplacent entièrement le dossier par défaut s’il existe.
